# Their Story WordPress Plugin

A basic WordPress plugin to power Their Story

## User Roles

- **Storyteller**: Can create and manage their own stories
- **Administrator**: Can view all stories, moderate submissions, and manage storytellers

## Installation

1. Upload the plugin files to `/wp-content/plugins/their-story/`
2. Activate the plugin through the WordPress admin panel
3. Create storyteller user accounts with the "Storyteller" role

## Usage

Storytellers can access their dashboard from the WordPress admin menu to create new stories. Each story generates a unique link that can be shared with visitors. Administrators have access to an "All Stories" dashboard to view and manage all stories and submissions.
